# Formulas
- 1 troy oz = 31.1034768 g
- Spot 24K (AED/g) = USD per oz / 31.1034768 × USD→AED rate
- Karat spot = 24K spot × purity (22K .916, 21K .875, 18K .75, 14K .585)
- Spread % = (retail − spot) / spot × 100
- Signal: ≤0.5% Strong Buy · ≤1.75% Good Buy · ≤3.5% Negotiate · above = Overpriced / Sell
- Break-even USD/oz = total cost / (grams × purity) × 31.1034768 / rate
